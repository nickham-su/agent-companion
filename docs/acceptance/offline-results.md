## 云端离线验证

阶段五验证时，从源码 ZIP 解压到项目内干净目录，新建虚拟环境，不安装当时的 `voice` 可选依赖、不传模型密钥、不登录飞书，也不接虚拟音频设备。统一验收入口为 `python -m unittest discover -s tests -v`，两个简短演示不替代它。安装和重建方法见 [README](../../README.md)，归档的 SHA256 与 ZIP 一起生成，不写进包内。

## 飞书多私聊复审回归（旧轮询历史）

模拟 CLI 和模型验证：包含无法分类记录的坏分页不会停用旧路由；完整快照明确排除旧绑定时会撤销路由。注入单笔 SQLite 锁冲突，验证同一会话按序消费、其他会话可继续处理、子任务受理不超额、归档与回投不重复，以及锁仍存在时可撤销并恢复尚未移交的批次。

用项目内临时 SQLite 的第二个连接制造真实锁冲突，验证回复提交失败后先回滚，解锁后只提交和发送一次；子回复已提交但结果查询被阻塞时，只重试该查询，子会话不重跑，父会话只收一次回投。故障注入另覆盖入站已消费和工具已归档后的上下文读取，不重复模型请求、历史摘要或工具执行。

## 飞书多私聊与自动接听：当前离线回归

在项目目录运行 `TMPDIR="$PWD" PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -q`。旧固定对端样例与用例已退出；`mode` 默认或显式为 `text` 时，阻断桌面、语音和 TTS 模块导入仍可开始私聊轮询；`voice` 在无旧配置键时按现有规则接听。回归覆盖三个已移除键被拒、Provider 启动、账号归属与未归属非空库保护，以及同一新测试库中 `text → voice → text` 的历史、语音打断及原私聊文字回执。普通演示和子任务演示均通过。上方阶段五记录保留为历史验收快照。

搜索版不再扫私聊列表。模拟 CLI 验证空闲单次搜索、分页和回看、全局去重、来源交叉校验、整批失败不推进、SQLite 原子入库与重启接续、按 `open_id` 外发及首次来电不等文字。

审查回归另覆盖：缺项和核验不符的候选不算已见，与同页及后续窗口正常输入隔离；持久退避、重启及迟到恢复；媒体槽被 A 占用时 B 的文字正常进入 Agent，下一轮仍能搜索；SQLite 暂锁不重做同批媒体；密集回看区从左到右二分、单秒超限告警退避且不跳过。真实原始 API 的返回形态、账号权限、媒体收录和搜索延迟仍待目标账号实机检查。

复审回归另验证：单条正文超限不阻塞水位或其他恢复项；可信 P2P 元数据更正后只按新依据核验，重启后只接收一次；相同回看命中不提前重试。原始 `mget` 的 `items: null` 或省略字段未确认为合法空结果，仍与鉴权、网络及其他协议失败一样不推进主水位。

在 Linux 用项目虚拟环境验证：**定向 107 项、全量 498 项均通过**。从项目根目录运行：

```sh
mkdir -p build/test-tmp
TMPDIR="$PWD/build/test-tmp" PYTHONPATH=src .venv/bin/python -B -m unittest discover -s tests -q
TMPDIR="$PWD/build/test-tmp" PYTHONPATH=src:tests .venv/bin/python -B -m unittest test_feishu test_feishu_private test_feishu_auto_answer test_agent_storage test_mvp_integration test_model_profiles
```

在 Linux 用模拟 CLI、窗口快照、模型、设备及合成 PCM 验证。覆盖 `text` 不监听来电、`voice` 每轮在音频静音就绪后只查一次、查询前复用浮窗时使用当前身份、查询期间换窗时不沿用旧结果、用户 Session 忙时本轮跳过、点击失败和接通超时后重新查询、浮窗还在时也能凭主窗口确认接通、设备未活跃和窗口消失处理，以及首次来电与文字共用主会话。接通后，仅隐藏但仍在全量列表中的窗口不会断开，窗口消失或枚举失败则停收停播。A→B 快速切换、同人重拨、排队的旧转写和迟到 ASR/TTS 均核对旧语音不进入新通话；旧模型停止后不续轮，已播放正文按回执保留，旧子任务不回投到新通话。挂断不影响仍在生成的文字回复。目标 Mac 的许可、`lark-cli` 响铃数据、真实点击、窗口生命周期和双路音频，按 [README](../../README.md#本机启用飞书自动接听)自行实机验收。

点击截止回归：使用可控单调时钟验证音频准备超过旧总时限仍可查询和接听，而查询结果过期后必须重新查询才能点击。在桌面替身中模拟指针移动、重新枚举窗口或准备鼠标事件期间到期，验证不发送按下或释放事件；若已发送按下，过期仍正常释放。
