# 首版验证记录

## 云端离线验证

从源码 ZIP 解压到项目内干净目录，新建虚拟环境，不安装 `voice` 可选依赖、不传模型密钥、不登录飞书，也不接虚拟音频设备。统一验收入口为 `python -m unittest discover -s tests -v`，两个简短演示不替代它。安装和重建方法见 [README](../../README.md)，归档的 SHA256 与 ZIP 一起生成，不写进包内。

阶段五验证环境为 Linux、Python 3.11.2、SQLite 3.40.1。云端 Python 未附带 `ensurepip`，因此从公开 PyPI 取得 pip 和构建／运行依赖的 wheel，保存在项目内，然后在解压目录以 `--no-index --find-links` 构建并安装源码，不复用工作区虚拟环境。`pip check` 无错误，已确认导入的是新环境内安装的包，**110 项离线测试全部通过**。连续重建的 ZIP 摘要一致，校验通过。

## 飞书多私聊复审回归

模拟 CLI 和模型验证：包含无法分类记录的坏分页不会停用旧路由；完整快照明确排除旧绑定时会撤销路由。注入单笔 SQLite 锁冲突，验证同一会话按序消费、其他会话可继续处理、子任务受理不超额、归档与回投不重复，以及锁仍存在时可撤销并恢复尚未移交的批次。

用项目内临时 SQLite 的第二个连接制造真实锁冲突，验证回复提交失败后先回滚，解锁后只提交和发送一次；子回复已提交但结果查询被阻塞时，只重试该查询，子会话不重跑，父会话只收一次回投。故障注入另覆盖入站已消费和工具已归档后的上下文读取，不重复模型请求、历史摘要或工具执行。
